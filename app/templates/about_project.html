About Project
Random Exchange

This project is a Stack Exchange–style web application built using HTML, CSS, JavaScript, Flask, and SQLite. The platform allows users to ask questions, post answers, and interact through a simple voting system. The main goal of the project is to create a clean and lightweight MVP that focuses on core community discussion features without unnecessary complexity. Flask handles the backend logic and routing, while SQLite is used for efficient database management. The project also follows a structured folder architecture and version control using Git. It is designed to help users learn full-stack development concepts such as authentication, database design, CRUD operations, and web application deployment.
